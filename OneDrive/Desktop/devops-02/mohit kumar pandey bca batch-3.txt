2.All steps of EC2 
(a) sign in into aws account
(b) go to searchbar and type EC2
(c) click EC2
(d) click launch instance
(e) give instance name like myserver
(f) choose AMI ubuntu windows etc.
(g) choose instance type like t2.micro
(h) create new key pair if you don't have download .pem file
(i) add rules (ssh (for connecting via terminal )
              (HTTP (for hosting website))
              (HTTPS (for usong ssl))
(j) click launch instance ->select your instance ->connect
