 How to Push Local Code to GitHub (Using Git Bash)
 
Prerequisites

✔ Git must be installed on your system (Git Bash for Windows).
✔ You must have a GitHub account.

Steps

1.Login to your GitHub account.

2.Create a new Repository (Repo).

3.Copy the HTTPS or SSH Repository URL.

 Command to push the code
1.git clone <repo_url>
2.git status
3.git add . 
4.git commit -m "your message"
5.git push
6.git checkout -b <branch_name>

🚀 How to Create an AWS EC2 Instance (Ubuntu)

1.Login to AWS Console.

2.Search for EC2 in the top search bar.

3.Click EC2 → Instances → Launch Instance.

4.Name your instance (any name is fine).

5.Choose OS: Select Ubuntu (or leave default AMI).

6.Instance Type: t2.micro (default and free-tier eligible).

7.Key Pair (Login):

If new → Create Key Pair

Key Type → RSA

File Format → .pem

Download and KEEP IT SAFE

8.Network Settings:

Allow SSH (port 22) — Anywhere or My IP

Allow HTTP (80) and HTTPS (443) if hosting websites.

9.Click Launch Instance
